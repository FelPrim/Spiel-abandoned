Задумавшись над тем, что я делаю, и над тем, что мне нужно было сделать, я осознал, что мне совершенно не нужна поддержка http/2 и http/3. Во-первых, у большинства потенциальных посетителей сайта просто не работает http/3. Во-вторых, сам сайт будет максимально легковесным и основная нагрузка будет приходиться на сообщения, которые нацелены на общение клиент-клиент где сервер является посредником. Поэтому использование h2o в моём проекте было неоправданно.

Перед сборкой либо установите зависимости сами, либо:  
1. Подтяните зависимости с помощью команды `git submodule update --init --recursive --depth 1`  
2. запустите build_deps_server.sh
